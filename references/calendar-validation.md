# 历表核验范围（2.1.0-local）

- 香港天文台：1950—2050年，共2424项二十四节气日期；2423项一致。
- 已知日期差异：1979年大寒，官方列1979-01-21，历法库算1979-01-20 23:59:56（UTC+8）。这是跨午夜差异，暂不猜测正确秒数或覆写引擎。
- 用于年/月切换和起运的十二“节”：1212项日期全部一致；上述大寒是“气”，不作为月柱或起运分界。
- 日本国立天文台：2010—2027年共432项节气时刻，统一从日本UTC+9换算至UTC+8，最大观察差值31秒。
- 对时刻回归的阈值为90秒；官方公布值为整分钟，此比较不等于秒级认证，也不证明其他年份时刻的误差上界。
- 官方来源共119份，提取结果和每份原文件SHA-256保存于calendar-fixtures.json。抽取原始文本位于本次工作缓存，未把整页原文复制进技能。

执行离线核验：
```
python -m unittest discover -s scripts -p "test_*.py"
```
当前29项测试通过，其中两项历表回归分别覆盖2424项日期和432项时刻。日期测试显式记录已知例外，不能把测试通过解释为2424项全一致。

注意：2027及之后的历表为官方预计算资料，不能称为已发生的观测。香港天文台提示远期节气时刻可能有分钟级不确定性；靠近午夜时日期可能变化。
