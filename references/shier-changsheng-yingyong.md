# 十二长生深度应用：从基础理论到断事择日

## 一、总论

**十二长生**是中国命理中最古老、最深刻的"生命周期模型"之一。它把任何五行的生命过程分为 12 个阶段，对应人的出生、成长、巅峰、衰老、死亡、转生。

> **基础参考**：`references/wuxing-tables.md` 已列出十二长生表（哪个天干在哪个地支处于哪个状态）。
>
> **本文件聚焦**：十二长生的**深度应用**——如何把这 12 个状态用到断事、择日、风水、人生阶段判断中。

### 为什么十二长生这么重要？

1. **判断五行强弱的细粒度工具**：不是只分"旺、衰"，而是分 12 个层次
2. **预测应期的关键钥匙**：某十神在何时"长生 / 帝旺 / 墓 / 绝"——对应该事在何时发动 / 巅峰 / 收藏 / 终结
3. **连接天干地支的桥梁**：天干在地支中的位置由长生决定
4. **人生阶段的精准映射**：胎养 → 长生 → 沐浴 → ... → 墓绝 = 人生从孕育到死亡的 12 个阶段

## 二、十二长生的基础含义详解

### 完整状态表（以阳干顺行为例）

| 序号 | 状态 | 别名 | 五行能量 | 人生对应 | 主何事 |
|------|------|------|---------|---------|--------|
| 1 | **长生** | 生 | 初生有气 | 婴儿期、刚出生 | 起始、希望、新生、开端 |
| 2 | **沐浴** | 败 / 桃花 | 不稳定 | 幼儿期、洗礼 | 不稳、桃花、改变、被冲击 |
| 3 | **冠带** | 带 / 冠 | 渐成熟 | 少年期、成人礼 | 学习、立志、成长、衣冠 |
| 4 | **临官** | 禄 / 临 | 成年充实 | 青年期、入职 | 任职、立业、得力、有所建树 |
| 5 | **帝旺** | 旺 / 王 | 极盛巅峰 | 壮年期、巅峰 | 极盛、过满、巅峰、易盛极而衰 |
| 6 | **衰** | / | 开始走下 | 中年初期 | 退转、衰减、稳定但开始下行 |
| 7 | **病** | / | 微病 | 中年中期 | 不顺、病气、犹豫、需调养 |
| 8 | **死** | / | 几尽 | 中年晚期 | 终结、休止、看不见出路 |
| 9 | **墓** | 库 / 葬 | 收藏 | 老年期 | 收藏、归库、保存、归宿 |
| 10 | **绝** | / | 全无 | 临终 | 断绝、空无、归零、即将转 |
| 11 | **胎** | / | 重新孕育 | 投胎 | 孕育、潜伏、看不见但有 |
| 12 | **养** | / | 即将出生 | 准备出生 | 蓄势待发、即将面世 |

### 十二阶段的核心含义图谱

```
        胎 ───→ 养
        ↑           ↓
        绝     长生
        ↑           ↓
        墓     沐浴
        ↑           ↓
        死     冠带
        ↑           ↓
        病     临官
        ↑           ↓
        衰  ←  帝旺
```

> **从胎到帝旺**：能量逐步上升（潜→显→盛）
> **从衰到墓绝**：能量逐步衰减（盛→衰→灭）
> **从胎养重启**：能量循环再生

### 十二长生的本质

> **十二长生是描述"任何能量从无到有、从盛到衰、从消失到重生"的完整周期模型**。

它可以用于：
- 看一个人 → 一生从生到死
- 看一段感情 → 从遇见到分开
- 看一份事业 → 从创业到结业
- 看一个项目 → 从启动到收尾
- 看一年 → 从立春到大寒
- 看一天 → 从子时到亥时

**通用性**是十二长生最强大的地方——任何"过程"都可以套用这 12 个阶段。

## 三、阴阳干长生的争议

### 流派分歧

#### 派别 A：阴阳同生异死（古法）

**主张**：阴干逆行长生
- 例：甲木长生在亥（顺行），乙木长生在午（逆行）
- 来源：《渊海子平》《三命通会》古典命理

**逻辑**：
- 阳干为体，阴干为用
- 阳干顺行，阴干逆行（取相反之意）

#### 派别 B：阴阳同生同死（盲派 / 现代）

**主张**：阴干不单独论长生，与阳干合论
- 例：乙木长生也算在亥（与甲同）
- 因为阴干本身能量较弱，长生死位都依附阳干

**逻辑**：
- 阴干"不能独立完成生命周期"
- 实战中阴阳同位更准

#### 派别 C：折中派

**主张**：用神 / 主气论用阳干长生（亥子寅卯等），调候 / 辅助论用阴干自身长生

### 本指南的立场

> **以"阴阳同生异死"（古法）为主**，原因：
> 1. 与《渊海子平》《滴天髓》等典籍一致
> 2. 与四柱预测的标准排法兼容
> 3. 阴干自有长生位时，对断事更精细
>
> **但实战中**：
> - 阳干长生位的能量更显著（直接论事）
> - 阴干长生位的能量较隐微（论暗动、论藏机）

详细的阴阳干长生表参见 `references/wuxing-tables.md`。

## 四、十二长生在命局中的应用

### 1. 看日干在四柱地支的状态

**步骤**：
1. 找到命主日干
2. 查日干在年、月、日、时四个地支中分别处于什么状态
3. 累加判断日主旺衰

**例**：
- 日干甲木
- 年支寅 → 甲在寅 = **临官**（强）
- 月支午 → 甲在午 = **死**（弱）
- 日支辰 → 甲在辰 = **衰**（中弱）
- 时支戌 → 甲在戌 = **养**（弱中有起）

**结论**：年柱有根（临官），但月日时三柱都弱 → 日主整体偏弱

### 2. 看十神在地支的状态

**这是十二长生最实用的应用之一**：

#### 看正官 / 七杀的强弱

**例**：日干甲木，正官为辛金
- 看辛金在四柱地支的长生状态
- 辛长生在子，沐浴在亥，冠带在戌，临官在酉，帝旺在申……
- 若命主时支为酉 → **辛官临官** → 官位有力 → 易升职、得权

**通用规则**：
- **官星临官 / 帝旺**：必有显赫官运
- **官星入墓**：官位被收藏，难以发挥
- **官星处绝地**：官星无力，难得权

#### 看财星的强弱

**例**：日干甲木，正财为己土，偏财为戊土
- 戊长生在寅，己长生在酉
- 若命主月支为寅 → **戊财长生** → 财运起步好，年轻进财

#### 看印星的强弱

**例**：日干甲木，正印为癸水
- 癸长生在卯
- 命主日支为卯 → **癸印长生在日支** → 一生贵人多、母亲缘深

### 3. 长生在四柱位置的不同含义

| 位置 | 含义 |
|------|------|
| 长生在**年柱** | 起步好、家世吉、童年顺 |
| 长生在**月柱** | 中年得力、事业有成 |
| 长生在**日柱** | 配偶贤、自身吉 |
| 长生在**时柱** | 子女好、晚年顺 |

| 位置 | 帝旺含义 |
|------|---------|
| 帝旺在年柱 | 早年极盛但需谨慎过满 |
| 帝旺在月柱 | 事业巅峰期长 |
| 帝旺在日柱 | 自身强势、配偶强势 |
| 帝旺在时柱 | 晚年高峰 / 子女出色 |

| 位置 | 墓库含义 |
|------|---------|
| 墓在年柱 | 早年沉郁、家世收敛 |
| 墓在月柱 | 中年阶段被收纳（可能是积累，也可能是停滞） |
| 墓在日柱 | 婚姻入墓（夫妻深沉，或感情冷淡） |
| 墓在时柱 | 晚年归藏、子女远离 |

| 位置 | 绝地含义 |
|------|---------|
| 绝在年柱 | 童年家世断绝感 |
| 绝在月柱 | 中年事业断流 |
| 绝在日柱 | 婚姻断缘、自我空虚 |
| 绝在时柱 | 子女缘薄 / 晚年孤独 |

## 五、十二长生在大运中的应用

### 大运的"长生级别"判断

**步骤**：看大运地支对日主、对用神的长生状态。

#### 例 1：用神为火

- 命主日干甲木，用神为火（食伤）
- 大运地支：寅（火长生）→ 用神起步好，但还未发力
- 大运地支：午（火帝旺）→ 用神最强，事业巅峰
- 大运地支：戌（火入库）→ 用神入墓，事业收敛但有积累
- 大运地支：亥（火绝）→ 用神断绝，事业大滑坡

#### 例 2：用神为金

- 命主日干壬水，用神为金（印星）
- 大运走丙申（火金）→ 申为金的长生 → 学历贵人开始多
- 大运走戊戌（土金墓）→ 戌为金的库 → 印星入库，需冲开才用得上
- 大运走辛丑（金土）→ 丑为金墓，但天干透辛 → 库中财发了

### 大运十二长生级别速查

| 级别 | 状态 | 大运评分（用神角度） |
|------|------|--------|
| ⭐⭐⭐⭐⭐ | 临官、帝旺 | 用神最旺运 |
| ⭐⭐⭐⭐ | 长生 | 用神起步运 |
| ⭐⭐⭐ | 冠带、养 | 用神预备运 |
| ⭐⭐ | 衰、胎 | 用神勉强运 |
| ⭐ | 沐浴、病 | 用神不稳运 |
| 0 | 死、墓 | 用神蛰伏运 |
| -1 | 绝 | 用神断流运 |

> ⚠️ 此为用神角度。**忌神**正好相反——忌神入绝、墓 = 大吉；忌神帝旺 = 大凶。

### 大运转换的关键节点

**入墓运 → 出墓运**：
- 例：用神入未库 + 大运正好走丑（丑未冲）→ 墓被冲开，用神大发
- 这是大运转换最关键的应期

**绝处逢生**：
- 用神在原命局处于绝地 + 大运走到长生 → 绝处逢生 = 翻身契机

## 六、十二长生在流年中的应用 ⭐

### 流年应期断事的核心规则

**规则**：某十神 / 某五行在某流年的长生状态 = 该事在该年的状态

**例**：求姻缘问题
- 男命：日干壬水，正财（妻星）为丁火
- 丁火长生在酉，帝旺在午，墓在丑，绝在子
- **断事**：
  - 走酉年 → 妻星长生 → 易遇感情萌芽
  - 走午年 → 妻星帝旺 → 感情最浓烈年（结婚 / 同居 / 生子）
  - 走丑年 → 妻星入墓 → 感情冷却 / 妻子身体不佳
  - 走子年 → 妻星绝 → 离婚 / 分手 / 妻子重病

### 流年应期典型断事

#### 1. 升职断事

- 命主日干 + 正官 / 七杀的长生位
- 走临官、帝旺年 → 必升职 / 中举 / 得权
- 走病死墓绝年 → 失意、调岗、被边缘化

#### 2. 财运断事

- 命主日干 + 财星的长生位
- 走长生、帝旺年 → 财源广进
- 走绝、墓年 → 破财、被骗、投资失败

#### 3. 婚姻断事

- 男命看正财 / 偏财
- 女命看正官 / 七杀
- 走配偶星的临官、帝旺、长生年 → 结婚最佳
- 走配偶星的衰病死墓年 → 不宜结婚（婚则有变）

#### 4. 健康断事

- 命主日干本身的长生状态
- 走自身死、绝年 → 健康警示
- 走自身长生、帝旺年 → 精力旺盛

#### 5. 学业断事

- 命主日干 + 印星的长生位
- 走印星临官、帝旺年 → 考试大利、学位获取
- 走印星墓绝年 → 考试失利

### 流年应期判断公式

```
应期年份 = 关键星宿（用神 / 配偶 / 财官等）的"临官 / 帝旺"地支所在的流年
```

**例**：
- 男命，求结婚年
- 妻星为辛金，辛临官在酉、帝旺在申
- 推断：**走酉年或申年最易结婚**
- 配合大运、流月可进一步精确

## 七、十二长生与十神的组合 ⭐⭐

### 1. 官星临帝旺 vs 官星入墓

**官星临帝旺**：
- 主**官位显赫、得权得力**
- 男命：升职、当官、有威信
- 女命：得贵夫、夫君有成就

**官星入墓**：
- 主**官位被收、退休、隐姓埋名**
- 男命：从领导岗退下、转幕后
- 女命：夫君不顺、夫妻聚少离多
- 若**库被冲开** → 突然出名 / 复出

### 2. 财星临长生 vs 财星处绝

**财星临长生**：
- 主**财源萌芽、新财路开始**
- 偏财长生：易得意外财
- 正财长生：稳定收入开始增长

**财星处绝**：
- 主**财源断流、破财、被骗**
- 男命：婚姻危机、配偶离弃
- 女命：财上不顺

### 3. 印星临冠带 vs 印星处死

**印星临冠带**：
- 主**贵人扶持、学有所成**
- 学生：考学得意
- 工作者：贵人提携

**印星处死**：
- 主**学业中断、贵人远离、母亲健康**
- 学生：考试失利
- 工作者：失去靠山

### 4. 食伤临帝旺 vs 食伤入墓

**食伤临帝旺**：
- 主**才华大显、子女出色**
- 创作者：出名、出版
- 母亲：子女有成

**食伤入墓**：
- 主**才华被埋、子女不顺**
- 创作者：作品被压下、失语
- 母亲：子女生病或学业问题
- 入墓后**冲开** → 复出 / 子女突变

### 5. 比劫临帝旺 vs 比劫入墓

**比劫临帝旺**：
- 主**朋友多、合作成、竞争激烈**
- 创业者：合伙人多但争利
- 领导者：下属多但难管

**比劫入墓**：
- 主**朋友疏远、独自前行**
- 不利合作
- 朋友离散

### 6. 七杀临帝旺 vs 七杀入墓

**七杀临帝旺**：
- 主**威权大显、压力极大、贵人或仇人都强**
- 武职：建功立业
- 商业：竞争白热化

**七杀入墓**：
- 主**贵人退场、仇人潜伏、压力消失**
- 紧绷一段后突然放松
- 但**冲开墓库** → 旧仇人复出 / 新挑战

## 八、十二长生与人生阶段对应 ⭐

### 把十二长生套用到人生

如果把"日干"看作"自己"，把人生看作"日干在大运中的旅程"，则：

| 人生阶段 | 长生阶段 | 主何事 |
|---------|---------|--------|
| 0-3 岁 | 胎养 | 孕育、依附、被养 |
| 3-15 岁 | 长生、沐浴 | 起步、学习、不稳定 |
| 15-25 岁 | 冠带、临官 | 成长、立志、入职 |
| 25-45 岁 | 帝旺 | 巅峰、最盛年 |
| 45-55 岁 | 衰、病 | 退转、调养 |
| 55-70 岁 | 死、墓 | 终结 / 收藏 |
| 70+ 岁 | 绝、胎 | 归零 / 准备转生 |

### 但每个人的"周期"不一样

**关键**：不是每个人都按"长生→帝旺"的顺序走大运。

**例**：阳男大运顺行 → 从月柱长生开始
**例**：阴女大运逆行 → 从月柱起逆数

所以个人"何时巅峰、何时衰退"完全因八字而异：
- 有人 30 岁巅峰、80 岁未衰
- 有人 60 岁才到巅峰
- 有人巅峰来得早、走得快
- 有人一辈子在"养胎"未真正发力

### 大运十二长生的性格映射

每一步大运可以问：
- "这十年我处于人生的哪个阶段？"
- "我应该重点发展什么？"

| 大运状态 | 该十年最适合 |
|---------|------------|
| 长生 | 学新技能、转行、新创业 |
| 沐浴 | 经历变动、不要重大决策 |
| 冠带 | 立志、成家、深入学习 |
| 临官 | 全力工作、立业、晋升 |
| 帝旺 | 收割成果、享受巅峰 |
| 衰 | 调整方向、传承、退居二线 |
| 病 | 调养身心、避免大动作 |
| 死 | 安静、归零、思考 |
| 墓 | 收藏、积累内功、深耕 |
| 绝 | 完全归零、迎接新生 |
| 胎 | 孕育新事、潜伏 |
| 养 | 蓄势待发、即将出关 |

## 九、十二长生与择日 ⭐

### 1. 用"长生日"做大事

**核心规则**：选择关键星临"长生 / 临官 / 帝旺"的日子

**应用举例**：

#### 开张择日
- 老板用神为木 → 选木的长生日 = **亥日**
- 期望偏财大旺 → 选偏财长生日

#### 婚嫁择日
- 妻星 / 夫星处临官、帝旺日
- 双方日干都不在死、绝日

#### 求医手术
- 选**医为印**：印星临冠带 / 临官日
- 避**杀为忌**：七杀帝旺日
- 命主日主**养、长生日**最佳（生命力强）

### 2. 避"墓绝日"

- 命主日干处墓日：精力衰退，不宜重要事
- 命主日干处绝日：能量断绝，避免冒险

### 3. 借"帝旺日"造大势

- 帝旺日 = 用神能量爆发日
- 适合：开市、签约、登台、表白
- 不适合：低调、隐藏、收尾事

### 4. 用"养、胎日"养护

- 养、胎日适合：调养身心、修身养性
- 不适合：积极进取（能量未足）

### 5. 与建除十二神的关系

十二长生 vs 建除十二神：

| 维度 | 十二长生 | 建除十二神 |
|------|---------|-----------|
| 本质 | 五行能量周期 | 日支与月建关系 |
| 起点 | 五行长生地 | 月建（月支） |
| 用途 | 看个人特定五行能量 | 看通用日子吉凶 |
| 个性化 | 高（按个人用神查） | 低（通用） |
| 配合 | 都用，互相参考 | 都用，互相参考 |

**最佳择日法**：
- 第一步：用建除十二神过滤"通用大凶日"
- 第二步：用十二长生选"个人最佳能量日"
- 两者重叠 = 最佳吉日

## 十、十二长生与风水

### 1. 长生方位的应用

每个五行有自己的"长生方位":

| 五行 | 长生方位 |
|------|---------|
| 木（甲） | 亥（西北偏北） |
| 火（丙） | 寅（东北偏东） |
| 土（戊） | 寅（同丙） |
| 金（庚） | 巳（东南偏南） |
| 水（壬） | 申（西南偏西） |

**应用**：
- 命主用神为木 → 在家中**西北偏北**方位摆放木气物（绿植、木雕）
- 该方位是"用神生气之地" → 长期催旺用神
- 比单纯"东方木气方"更精细

### 2. 帝旺方位的应用

| 五行 | 帝旺方位 |
|------|---------|
| 木 | 卯（正东） |
| 火 | 午（正南） |
| 土 | 午（同火） |
| 金 | 酉（正西） |
| 水 | 子（正北） |

**应用**：
- 用神帝旺方位 = 用神能量最强方位
- 此处摆放招财物、命主常待
- 但要注意"帝旺即将转衰"——能量过满需平衡

### 3. 墓位的应用

| 五行 | 墓位 |
|------|------|
| 木 | 未（西南偏南） |
| 火 | 戌（西北偏西） |
| 土 | 戌（同火） |
| 金 | 丑（东北偏东） |
| 水 | 辰（东南偏东） |

**应用**：
- 墓位 = 五行能量的收藏处
- **财库**就在自己财星的墓位
- 例：男命财为水 → 财库在辰 → 家中**东南偏东**方位是财库 → 此处放保险柜、金库
- 用神入库需冲开（流年走对应冲位）

### 4. 绝位的避忌

| 五行 | 绝位 |
|------|------|
| 木 | 申（西南偏西） |
| 火 | 亥（西北偏北） |
| 土 | 亥（同火） |
| 金 | 寅（东北偏东） |
| 水 | 巳（东南偏南） |

**应用**：
- 用神的绝位 = 用神最弱方位
- 命主**避免长时间在用神绝位**
- 卧室、办公桌不宜放在用神绝位

## 十一、典型应用案例

### 案例 1：求婚姻应期

**命主**：男，1990 庚午年生
**八字**：庚午 庚辰 戊寅 壬戌
- 日干戊土，妻星（正财）为癸水，偏财为壬水
- 时干透壬偏财 → 偏财显
- 癸水（正财）长生在卯，帝旺在子，墓在辰，绝在午
- 壬水（偏财）长生在申，帝旺在子，墓在辰，绝在巳

**流年扫描**（25 岁后）：

| 流年 | 妻星状态 | 主断 |
|------|---------|------|
| 2015 乙未（25 岁） | 癸（正财）在未 = 衰 | 感情平淡 |
| 2016 丙申（26 岁） | 壬（偏财）在申 = **长生** | 桃花起、易遇人 |
| 2017 丁酉（27 岁） | 癸（正财）在酉 = 沐浴 | 感情不稳 |
| 2018 戊戌（28 岁） | 戊为命主自身在戌 = 墓 | 自身入墓不动 |
| 2019 己亥（29 岁） | 癸（正财）在亥 = 临官 | **正财临官，结婚良机** |
| 2020 庚子（30 岁） | 癸（正财）在子 = **帝旺**；壬（偏财）在子 = **帝旺** | **婚姻最佳年** ⭐⭐⭐⭐⭐ |

**结论**：命主最易结婚的年份在 **2019-2020**，2020 年最强。
若错过 → 下一个高峰看 2025（乙巳年，正财在巳为胎，不利）→ 2027（丁未年，正财在未为衰）→ 2032（壬子年，正财帝旺重现）

### 案例 2：判断创业最佳时机

**命主**：女，1985 乙丑年生
**八字**：乙丑 庚辰 丁未 甲辰
- 日干丁火，用神为木（生火）
- 重点星：偏财（庚金）、正官（壬水）、印（甲乙木）
- 甲木（印）长生在亥，临官在寅，帝旺在卯
- 庚金（偏财）长生在巳，临官在申，帝旺在酉

**事业大运扫描**：

| 大运（10 年） | 关键状态 | 主断 |
|------------|---------|------|
| 28-37 癸未 | 七杀坐墓 → 用神不显 | 打工期、被压制 |
| 38-47 壬午 | 正官坐胎，比劫帝旺（午为丁火帝旺）→ 自身极强 | **创业巅峰期** ⭐⭐⭐⭐⭐ |
| 48-57 辛巳 | 偏财长生在巳 → 财源开始 | 创业稳定期 |
| 58-67 庚辰 | 偏财坐墓 → 财气收敛 | 财库阶段，传承期 |

**关键流年**：
- 38 岁是 2023 年（癸卯，印帝旺）→ 创业**起步年**
- 39-40 岁（甲辰、乙巳）→ 印星帮身、印星到位 → 资源整合年
- 42-43 岁（丁未、戊申）→ 比劫透出、偏财长生 → 团队 + 财源齐到
- 44 岁（己酉）→ 偏财帝旺 + 食神生财 → **最佳获利年**

**建议**：
- 2023 年起步、2026 年加速
- 2028-2029 年是黄金获利期
- 2030 年后稳定经营，准备 48 岁后传承

### 案例 3：择日开店

**老板**：男，用神为木，正财为戊土
**目的**：2026 年开店，求最佳吉日

**思路**：
- 用神木的临官 = 寅日
- 用神木的帝旺 = 卯日
- 财星戊土的长生 = 寅日
- 财星戊土的临官 = 巳日
- 财星戊土的帝旺 = 午日

**重叠最佳日**：
- **寅日** = 用神临官 + 财星长生 = 双吉
- **卯日** = 用神帝旺 = 用神最强
- **午日** = 财星帝旺，但午为忌神（火克金，老板用神金不在此案）→ 因为本案用神为木，午日仍为木的死位，不取

**首选**：寅日（六十甲子的甲寅、丙寅、戊寅、庚寅、壬寅）
**次选**：卯日

配合 `references/zeri.md` 的择日方法（避建除凶日、避岁破等），从 2026 年中筛选满足"寅 / 卯日 + 不冲命主 + 不犯凶煞"的日子。

## 十二、与现代生命周期理论的对照

### 1. 经济学：康德拉季耶夫长波

康波周期（约 50-60 年）：
- 萌芽 → 成长 → 巅峰 → 衰退 → 萧条 → 复苏
- 类似于**胎养 → 长生 → 冠带临官 → 帝旺 → 衰病死 → 墓绝 → 胎养**
- 中国术数早 1500 年用"十二长生"提出了类似模型

### 2. 产品生命周期理论

产品生命周期（5 阶段）：
- 引入期 → 成长期 → 成熟期 → 衰退期 → 退出
- 对应十二长生的"长生 → 临官 → 帝旺 → 衰病 → 墓"
- 营销学的"产品生命周期"几乎是十二长生的简化版

### 3. 人生发展心理学

埃里克森八阶段：
- 婴儿期 → 幼儿期 → 学龄前 → 学龄期 → 青春期 → 成年早期 → 成年中期 → 成年晚期
- 对应十二长生的胎、养、长生、沐浴、冠带、临官、帝旺、衰
- 都是"渐进式发展"模型

### 4. 哈佛人生研究

格兰特研究（80 年纵向研究）：
- 发现人生在不同阶段优先级不同
- 与十二长生在大运中的不同侧重高度吻合

### 5. 中医脏腑节律

中医认为脏腑功能在人生中有节律：
- 25-30 岁脾气盛
- 30-40 岁肝气盛
- 40-50 岁心气盛
- 50-60 岁肾气盛
- 与十二长生在中医五行配脏腑上有对应

> 这些跨学科证据表明：**十二长生不是迷信，而是中国古人对"生命周期"的早期数学化模型**——只是表达方式是用阴阳五行符号。

## 十三、十二长生综合应用速查表

### 看日主旺衰
- 日干在月支处长生、临官、帝旺 = 日主旺
- 日干在月支处衰、病、死、墓、绝 = 日主弱

### 看用神能量
- 用神在大运 / 流年地支处帝旺 = 用神最强 = 大吉年
- 用神在大运 / 流年地支处死、绝 = 用神最弱 = 大凶年
- 用神在大运 / 流年地支处墓 = 用神入库 = 平年（除非冲开）

### 看忌神能量（与用神反向看）
- 忌神帝旺 = 大凶
- 忌神入墓 / 绝 = 大吉

### 看应期
- 求事之年：找该事所对应的星处于"长生 / 临官 / 帝旺"的流年
- 避事之年：避开该事所对应的星处于"死 / 墓 / 绝"的流年

### 看人生阶段
- 大运临官 / 帝旺 = 人生巅峰期
- 大运衰、病 = 人生退转期
- 大运墓、绝 = 人生收藏期 / 转折期
- 大运胎、养 = 人生准备期

### 看择日
- 选用神的"临官 / 帝旺日" = 最佳吉日
- 避忌神的"帝旺日" = 最大凶日
- 用神的长生日 = 起步好日

### 看风水方位
- 用神长生方位 = 用神生气之处，宜常待
- 用神帝旺方位 = 用神最强处，宜放招财物
- 用神墓位 = 用神收藏处，宜放保险柜
- 用神绝位 = 用神最弱处，避免长时间停留

## 十四、常见 FAQ

### Q1：阳干顺行、阴干逆行，到底怎么排？
A：本指南采用古法。具体表见 `wuxing-tables.md`。实战中阴干长生位的能量比阳干弱，所以**断事时阳干长生位的信号更明确**。

### Q2：十二长生与"旺相休囚死"是一回事吗？
A：**不是同一套**。
- "旺相休囚死"是月令对五行的态度（5 个状态）
- 十二长生是天干在地支的状态（12 个细分阶段）
- 两者可互参，但不能混用

### Q3：长生比帝旺还好吗？
A：**两者各有特点**：
- 长生：起步、有希望、但还未发力
- 帝旺：巅峰、能量最强、但易盛极而衰
- **长生 + 流年 + 大运配合**才能爆发
- **帝旺独自存在**也能显威，但需注意保护

### Q4：墓库是好事还是坏事？
A：**视用神 / 忌神而定**：
- 用神入库 = 收藏好东西，但需冲开才能用 = 中性偏吉
- 忌神入库 = 收藏坏东西，安静潜伏 = 中性偏吉
- 关键是**有没有冲开 / 何时冲开**

### Q5：流年走到自己日干的"死"位，是不是真的会死？
A：**不是字面意思**。"死"是十二长生中的一个状态，主**精力衰退、做事不顺、需要调养**。**不要望文生义恐慌**。健康风险确实增加，但不必然致命。

### Q6：怎么把十二长生用到日常决策？
A：**简化版三问法**：
1. 我现在想做的事，对应什么星？（财、官、印、食伤等）
2. 这个星在今年的地支里是什么状态？
3. 临官帝旺 = 大胆做；衰病死 = 谨慎做；墓绝 = 不做或推迟

## 十六、本指南的核心总结

> 1. **十二长生是"能量周期"的精细化模型**——任何过程都可套用
> 2. **应用层级**：日主旺衰 → 十神状态 → 大运强弱 → 流年应期 → 择日吉凶 → 风水方位

> 4. **应期断事的钥匙**：找出"关键星"的临官、帝旺位 → 那是事件发生的最可能流年
> 5. **不要望文生义**："死"不是死亡，"墓"不是入土——它们是**能量状态**的描述
