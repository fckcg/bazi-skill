# 六爻辅助断事入门

## 一、总论

**六爻**（又称"金钱卦""文王卦""周易卜筮"）是中国术数中应用最广、起卦最便捷的占卜方法之一。它源自《周易》，由汉代京房创立"纳甲法"完整体系，唐宋以后成为民间最普及的占卜工具。

> **本指南的定位**：
> - 不是六爻系统教程（六爻自有数百本专书）
> - 而是**八字命理使用者的辅助工具**
> - 当八字遇到模糊问题时，用六爻补充判断
>
> **典型场景**：
> - 八字看出"今年某月有变动" → 用六爻问"这个变动是吉是凶"
> - 八字看出"感情有动" → 用六爻问"这段感情能否长久"
> - 八字看出"事业转机" → 用六爻问"具体往哪个方向转"

### 八字 vs 六爻的对比

| 维度 | 八字 | 六爻 |
|------|------|------|
| 看什么 | 终身命运 + 大势 | **当下具体事**（眼前问题） |
| 时间精度 | 流年→流月（年到月） | 应期可精确到日 |
| 适用范围 | 整体运势（性格、健康、婚姻） | 具体一件事（成不成、何时成） |
| 起手准备 | 需要完整出生时间 | 任意时间 + 摇卦即可 |
| 学习成本 | 中高 | 中（基础部分较易） |
| 准确率 | 60-75%（趋势） | 60-70%（具体事） |

### 何时用八字？何时用六爻？

**用八字的场景**：
- "我这一辈子是什么命？"
- "我适合什么行业？"
- "我什么时候会结婚？"（应期范围）
- "我的身体有什么风险？"

**用六爻的场景**：
- "我这次考试能过吗？"
- "我和这个对象能在一起吗？"
- "这个项目能赚钱吗？"
- "我丢的东西能找回来吗？"
- "他什么时候回来？"

**两者结合的最佳场景**：
- 八字看出趋势 → 六爻确认具体事
- 八字模糊不清 → 六爻补充明确

## 二、六爻的基础知识

### 1. 八卦速记

**八经卦**（八卦）：

| 卦 | 符号 | 卦名 | 五行 | 八卦象 |
|----|-----|------|------|------|
| 乾 | ☰ | 乾 | 金 | 天、父、首领 |
| 兑 | ☱ | 兑 | 金 | 泽、少女、口 |
| 离 | ☲ | 离 | 火 | 火、中女、目 |
| 震 | ☳ | 震 | 木 | 雷、长男、足 |
| 巽 | ☴ | 巽 | 木 | 风、长女、股 |
| 坎 | ☵ | 坎 | 水 | 水、中男、耳 |
| 艮 | ☶ | 艮 | 土 | 山、少男、手 |
| 坤 | ☷ | 坤 | 土 | 地、母、腹 |

**记忆口诀**（朱熹《八卦取象歌》）：
> 乾三连，坤六断；
> 震仰盂，艮覆碗；
> 离中虚，坎中满；
> 兑上缺，巽下断。

### 2. 六十四卦的构成

- 八卦两两相叠 = 8 × 8 = **64 卦**
- 每卦有 6 爻
- 上面 3 爻 = 上卦（外卦）
- 下面 3 爻 = 下卦（内卦）

**例**：
- 上乾 + 下坤 = **天地否**（䷋）
- 上坤 + 下乾 = **地天泰**（䷊）

### 3. 爻位

每卦从下往上数：

```
六爻（上爻） →   －－
五爻       →   －－
四爻       →   －－
三爻       →   －－
二爻       →   －－
初爻（最下）→   －－
```

**爻位含义**：
- 初爻：开始、底层、初期
- 二爻：内卦中位、家中、私事
- 三爻：内卦顶、转折点
- 四爻：外卦底、外部初接
- 五爻：外卦中位、君位、领导
- 六爻：外卦顶、终结、退位

### 4. 阳爻与阴爻

- **阳爻**（⚊）= 实线 = 一画
- **阴爻**（⚋）= 断线 = 两画

每爻有四种状态：
- 静爻阳：⚊（不动）
- 静爻阴：⚋（不动）
- 动爻阳变阴：⚊ → ⚋（"老阳变阴"）
- 动爻阴变阳：⚋ → ⚊（"老阴变阳"）

**动爻**是六爻断卦的**最关键元素**——它代表"变化的方向"。

## 三、起卦方法

### 1. 三个铜钱法（最常用）

**工具**：3 枚铜钱（圆形方孔最佳）或 3 枚硬币

**步骤**：
1. 双手合十铜钱、心中默念问题
2. 摇 6 次，每次记录 3 枚的正反面
3. 从下往上依次记录（第 1 次为初爻）

**铜钱组合解读**：
- 3 个正面（无字面）= **老阳**（动爻，⚊→⚋）记 □
- 3 个反面（有字面）= **老阴**（动爻，⚋→⚊）记 X
- 2 正 1 反 = **少阴**（静爻 ⚋）记 - -
- 1 正 2 反 = **少阳**（静爻 ⚊）记 ──

**简化记忆**：
- 字面（"中华人民共和国"等）算阴
- 花面（图案）算阳
- 3 字 = 老阴动；3 花 = 老阳动；2 字 1 花 = 少阳；2 花 1 字 = 少阴

### 2. 报数起卦法（无铜钱时用）

请问卦人**报 3 个数字**：

**方法 A：用三个数取卦**
- 数字 1 ÷ 8 余数 = 上卦数
- 数字 2 ÷ 8 余数 = 下卦数
- 数字 3 ÷ 6 余数 = 动爻位

**八卦数序**（先天八卦）：
1. 乾、2. 兑、3. 离、4. 震、5. 巽、6. 坎、7. 艮、8. 坤

**例**：
- 报数：47, 12, 25
- 47 ÷ 8 = 5 余 7 → 上卦艮
- 12 ÷ 8 = 1 余 4 → 下卦震
- 25 ÷ 6 = 4 余 1 → 动爻初爻

→ 卦：山雷颐 + 初爻动 → 变卦：山地剥（初爻变阴）

### 3. 时间起卦法（梅花易数）

用**起卦时刻**起卦：

- 上卦 = （年支数 + 月数 + 日数）÷ 8 余数
- 下卦 = （年支数 + 月数 + 日数 + 时支数）÷ 8 余数
- 动爻 = （上面四个数总和）÷ 6 余数

年支数 = 子 1、丑 2、寅 3、……、亥 12
月数、日数、时支数照实

### 4. 起卦注意事项

**起卦前的"诚"**：
- 心要诚、问题要明确（不能模糊）
- 一事一卦（不要混问）
- 同一问题三次以上 = 不灵（"不诚"）

**问题的提法**：
- ✅ "我这次面试腾讯能录用吗？" （明确）
- ❌ "我未来怎么样？" （模糊）

**不要问的问题**：
- 别人的隐私（道德底线）
- 已经知道答案的（无意义）
- 不可改变的事（如已死之人寿命）

## 四、装卦：纳甲与六亲

### 1. 装天干地支（纳甲）

每一卦的 6 爻按"纳甲"规则配上天干地支。这是六爻断卦的核心步骤。

**纳甲规则**（按上下卦分别记）：

| 卦 | 内卦（下卦）纳支 | 外卦（上卦）纳支 |
|----|------------|-----------|
| 乾 | 子寅辰（初二三） | 午申戌（四五六） |
| 坎 | 寅辰午 | 申戌子 |
| 艮 | 辰午申 | 戌子寅 |
| 震 | 子寅辰 | 午申戌 |
| 巽 | 丑亥酉 | 未巳卯 |
| 离 | 卯丑亥 | 酉未巳 |
| 坤 | 未巳卯 | 丑亥酉 |
| 兑 | 巳卯丑 | 亥酉未 |

**简化记忆**：
- 乾、震 内卦：子寅辰
- 乾、震 外卦：午申戌
- 坎 内卦：寅辰午（顺移 1 位）
- 坎 外卦：申戌子（顺移 1 位）
- ……依此类推

### 2. 装六亲

**六亲**根据本卦五行 vs 各爻五行的关系定：

| 关系 | 六亲 |
|------|------|
| 同我者（与本卦五行相同） | 兄弟 |
| 我生者（本卦五行所生） | 子孙（食伤） |
| 我克者（本卦五行所克） | 妻财 |
| 克我者（克本卦五行的） | 官鬼 |
| 生我者（生本卦五行的） | 父母 |

**注**：本卦五行 = 本卦的"卦宫"五行（八宫卦的归属）。

**八宫卦表**：

| 宫 | 卦宫五行 | 包含的卦 |
|----|--------|---------|
| 乾宫 | 金 | 乾、姤、遁、否、观、剥、晋、大有 |
| 坎宫 | 水 | 坎、节、屯、既济、革、丰、明夷、师 |
| 艮宫 | 土 | 艮、贲、大畜、损、睽、履、中孚、渐 |
| 震宫 | 木 | 震、豫、解、恒、升、井、大过、随 |
| 巽宫 | 木 | 巽、小畜、家人、益、无妄、噬嗑、颐、蛊 |
| 离宫 | 火 | 离、旅、鼎、未济、蒙、涣、讼、同人 |
| 坤宫 | 土 | 坤、复、临、泰、大壮、夬、需、比 |
| 兑宫 | 金 | 兑、困、萃、咸、蹇、谦、小过、归妹 |

**六亲装法举例**：
- 求得卦：离卦（离宫）→ 卦宫五行 = 火
- 各爻五行：从下往上 = 卯木、丑土、亥水、酉金、未土、巳火
- 六亲：
  - 卯木：生火（火宫）= 父母
  - 丑土：火宫所生 = 子孙
  - 亥水：克火（火宫）= 官鬼
  - 酉金：火宫所克 = 妻财
  - 未土：火宫所生 = 子孙
  - 巳火：与火宫同类 = 兄弟

### 3. 装世应

**世**：当事人（求卦者）
**应**：对方 / 客观环境 / 所求之事

**装世应规则**（八宫卦不同）：
- 乾兑宫：世在五爻、应在二爻
- 坤艮宫：世在四爻、应在初爻
- 震巽宫：世在初爻、应在四爻
- 坎离宫：世在三爻、应在六爻

（实际六爻有更详细的"游魂归魂"装法，本指南简化）

**意义**：
- **世爻** = 自己
- **应爻** = 对方 / 事
- 世应关系 = 自己和事情的关系

## 五、世应、用神、原神、忌神

### 1. 用神

**用神** = 所求之事在卦中的代表爻

**对应表**：

| 求问类型 | 用神（六亲） |
|---------|-----------|
| 自己 / 当事人 | 世爻 |
| 父母、长辈、合同、文书 | 父母爻 |
| 兄弟、朋友、合伙人 | 兄弟爻 |
| 子女、晚辈、技艺、医药 | 子孙爻 |
| 财物、妻子（男）、收益 | 妻财爻 |
| 工作、上司、丈夫（女）、官非 | 官鬼爻 |

**例**：
- 问："我儿子学业如何？"
- 用神 = 子孙爻
- 看子孙爻在卦中的状态

### 2. 原神

**原神** = 生用神的爻

**例**：
- 用神为子孙爻（如丑土子孙）
- 原神 = 生土的爻 = **兄弟爻**（火生土，但实际是火宫所生为土，即父母爻？）

> 这里有个常见混淆：六亲的"生克"与五行的生克是**两回事**。
> - 六亲是"用神 ↔ 其他爻"的关系标签
> - 五行生克是"看用神能不能受生 / 受克"

**原神判断**：
- 看用神**五行**
- 找生该五行的**其他爻**
- 那个爻就是原神

**例**：
- 用神是子孙丑土
- 生土的五行 = 火
- 卦中的火爻 = 原神

### 3. 忌神

**忌神** = 克用神的爻

**例**：
- 用神是子孙丑土
- 克土的五行 = 木
- 卦中的木爻 = 忌神

### 4. 仇神

**仇神** = 生忌神的爻
- 间接影响用神
- 一般作辅助考虑

### 5. 用神判断的核心规则

**用神有力 = 事可成**：
- 用神临月建（旺）
- 用神临日建（旺）
- 用神被动爻生（受生）
- 用神化吉（动而变好爻）
- 原神也旺

**用神无力 = 事难成**：
- 用神被克（被忌神克）
- 用神入墓（藏库不出）
- 用神空亡（虚而无）
- 用神被合（被合住不动）
- 用神化凶（动而变坏）

## 六、断卦的基本步骤（七步法）⭐

### 第 1 步：明确问题、确定用神
- 你问的什么事？
- 该事对应哪个六亲？
- 锁定用神爻

### 第 2 步：起卦、装卦
- 用上述方法起卦
- 装上天干地支、六亲、世应

### 第 3 步：看用神状态
- 用神在哪一爻？
- 用神的五行是什么？
- 用神临月建、日建吗？
- 用神被动爻生 / 克 / 合 / 冲？

### 第 4 步：看原神 / 忌神
- 原神有力 → 用神有靠
- 忌神动 → 用神受损

### 第 5 步：看动爻
- 哪些爻发动？（铜钱时为老阴 / 老阳）
- 动爻 = "事情在动"
- 动爻克用神 → 该爻代表的人 / 事在阻碍
- 动爻生用神 → 该爻代表的人 / 事在帮助

### 第 6 步：看世应关系
- 世应相生 → 你与事 / 对方有缘
- 世应相克 → 你与事 / 对方对立
- 世应同类 → 同进退
- 世应空亡 → 缺一方意愿

### 第 7 步：综合断结果
- 用神旺 + 原神旺 + 动爻有利 = **大吉**
- 用神弱 + 忌神动 + 动爻不利 = **大凶**
- 中间各种组合 = 各种结果

## 七、应期判断

**应期** = 事情何时发生（对六爻最有价值的功能！）

### 1. 应期判断口诀

> **静则逢冲、动则逢合、合则逢冲、冲则逢合、空则待实、墓则待开、衰则待旺**

### 2. 详细规则

**静爻**（不动）应在**冲日**：
- 用神为申金，静爻
- 应期 = 寅日（申冲寅）

**动爻**（动起来）应在**合日**：
- 用神为申金，动爻
- 应期 = 巳日（申巳合）

**合住的爻**应在**冲日**：
- 用神被合住
- 应期 = 冲开合的那天

**冲动的爻**应在**合日**：
- 用神被冲动
- 应期 = 合住的那天

**空亡的爻**应在**填实日**：
- 用神在空亡
- 应期 = 出空填实的日子

**入墓的爻**应在**冲库日**：
- 用神入库（如金入丑库）
- 应期 = 冲开库的日子（未冲丑）

**衰弱的爻**应在**旺日 / 旺月**：
- 用神衰
- 应期 = 用神当令的月份

### 3. 应期的精度

- **大事** → 应在月（用神所旺月）
- **中事** → 应在日（按上述规则）
- **小事** → 应在时（按时辰）
- **远事** → 应在年（用神所旺年）

### 4. 应期举例

**问**："我什么时候能找到工作？"
**用神**：官鬼爻（官鬼为工作）
**卦中**：官鬼酉金，静爻临月建（当令）
**应期判断**：
- 静爻 → 应在冲日
- 酉冲卯 → 卯日应
- 用神有力 → 必能找到
- 综合：**下个卯日（具体看万年历）找到工作**

## 八、与八字配合的实战

### 1. 八字模糊处用六爻补充

#### 场景 A：八字看出"今年某月有变动"，但不知好坏

**八字判断**：流月辛酉冲日支卯木（夫妻宫）→ 必有动
**六爻补充**：
- 摇卦问"这次变动是好是坏？"
- 看用神（世爻为自己）状态
- 用神得生 → 变动是好（升职 / 搬家有利）
- 用神被克 → 变动是坏（失业 / 婚变）

#### 场景 B：八字看出"事业转机"，但不知具体方向

**八字判断**：今年财大运 + 流年食伤生财 → 有创业机会
**六爻补充**：
- 摇卦问"我应该 A 还是 B 方向？"
- 起两次卦分别问 A、B
- 比较两卦的世爻状态、用神状态
- 选用神更有力的方向

#### 场景 C：八字看出"健康有警示"，但不知严重程度

**八字判断**：今年水克火 + 心血管警示
**六爻补充**：
- 摇卦问"今年是否会有重大健康问题？"
- 子孙爻为医药、用神为世爻
- 子孙爻有力（医药能治） + 用神不衰 = 警示但不严重
- 子孙爻无力 + 用神被克 = 必须立即就医

### 2. 八字 + 六爻的综合判断流程

```
第 1 步：八字看大势（一年的整体）
第 2 步：八字看流月（哪个月最关键）
第 3 步：六爻细化具体事件（这件事能否成）
第 4 步：六爻判断应期（具体哪一天）
第 5 步：综合给出可执行建议
```

## 九、典型应用案例

### 案例 1：求职面试

**情境**：命主 8 月 15 日面试，问能否录用

**摇卦结果**（假设）：
- 卦象：天火同人 → 天水讼（六爻动）
- 卦宫：离宫，五行火
- 装六亲：
  - 上九：戌土 → 子孙
  - 九五：申金 → 妻财
  - 九四：午火 → 兄弟
  - 九三：亥水 → 官鬼
  - 六二：丑土 → 子孙（动）
  - 初九：卯木 → 父母

**用神**：官鬼亥水（求工作看官鬼）
- 月建为申月：申金生亥水 → 用神得月生 ⭐
- 日建假设为庚午日：午火被亥水克，但日干庚金生亥水 → 日建相生
- 用神状态：旺、有靠

**动爻**：六二丑土（子孙）动，子孙克官 → 不利
- 但子孙是动爻 → 需看变化
- 丑土动变什么？六爻动为子动变本爻或变什么……（实际需看卦变到讼卦）

**综合判断**：
- 用神官鬼亥水有月日相助 → 工作机会有 ⭐
- 但子孙动克官 → 有阻力（可能是其他竞争者）
- 应期：用神动则逢合，亥合寅 → 下个寅日有结果

**断**：约一周内有回音，最终能录用，但有竞争。

### 案例 2：感情发展

**情境**：女命问"我和现在的男朋友能结婚吗？"

**摇卦结果**（假设）：
- 卦象：泽地萃（兑上坤下）
- 卦宫：兑宫，五行金
- 装六亲：
  - 上六：未土 → 父母
  - 九五：酉金 → 兄弟
  - 九四：亥水 → 子孙
  - 六三：卯木 → 妻财
  - 六二：巳火 → 官鬼（用神！女命问婚看官鬼为夫）
  - 初六：未土 → 父母

**用神**：六二巳火（女命求夫为官鬼）
- 月建假设为亥月：亥水克巳火 → 用神被月克
- 日建假设为丙寅日：寅木生火 → 但日支寅冲申……（看卦中无申）

**动爻**：假设无动爻（全静卦）

**世应**：兑宫世在五爻、应在二爻
- 世爻酉金：旺
- 应爻巳火（即用神）：被月克

**综合判断**：
- 用神被月建克 → 关系有大压力
- 世旺应弱 → 命主自身强、对方弱
- 世应五行：金克火 → 命主在压制对方
- **结论**：感情中你处于强势，对方较弱、易退出。短期可能在一起，长期不易稳定。

**应期**：用神静爻 → 逢冲日应
- 巳冲亥 → 下个亥月或亥日有重大变化

### 案例 3：寻找丢失物品

**情境**：丢了手机，问能否找回

**摇卦**：求得"水火既济"，无动爻

**用神**：妻财（财物）

**装六亲**后看妻财爻位置：
- 假设妻财在初爻（地下、最深处）
- 看妻财五行、状态：得月日生 → 物在但不易立即找到

**应期判断**：
- 静爻 → 逢冲日
- 假设妻财午火 → 子日（子冲午）有线索

**断**：物品未失，藏于角落 / 床下 / 较隐蔽处。子日有人提及或自己想起。

### 案例 4：求医问诊

**情境**：得了病，问能否治愈

**摇卦**：得"火水未济"

**用神判断**：
- 自己 = 世爻
- 病 = 官鬼爻
- 医药 = 子孙爻

**关键看**：
- 世爻状态（自身体质）
- 官鬼状态（病的程度）
- 子孙状态（医药效果）

**理想情况**：
- 世爻旺
- 官鬼空 / 衰
- 子孙旺动克官鬼

**不利情况**：
- 世爻衰
- 官鬼旺动克世
- 子孙空 / 衰 / 受克

**应期**：
- 子孙旺动 → 治疗起效在子孙临旺日
- 用神官鬼伏藏 → 病在某月发作
- 等等

## 十、与八字的边界 ⭐

### 1. 六爻不能替代八字的事

- ❌ 看一辈子的整体命运
- ❌ 看性格、潜质
- ❌ 看大趋势（多年范围）
- ❌ 看体质 / 健康基础

### 2. 八字不能替代六爻的事

- ❌ 看一件具体事的成败
- ❌ 看应期到日 / 时
- ❌ 看具体方向选择（A or B）
- ❌ 看不在场的人 / 物状态

### 3. 两者结合的最佳模式

```
=== 模式 1：八字定方向，六爻定细节 ===

八字："您 35 岁那年是事业转机年" （年）
六爻：摇卦问"我下半年应该跳到 A 公司还是 B 公司？" （细节）
结合：35 岁转机 + B 公司用神更有力 → B 公司是答案

=== 模式 2：八字预测、六爻验证 ===

八字："您今年 8 月有桃花" （预测）
六爻：摇卦问"我 8 月会遇到结婚对象吗？" （验证）
结合：八字 + 六爻一致 → 信心更强

=== 模式 3：八字模糊、六爻明确 ===

八字："您未来某年会创业" （模糊）
六爻：摇卦问"我现在创业能成吗？" （明确）
结合：六爻给出当下答案
```

### 4. 何时不必用六爻

- 命主已经决定了 → 不用问
- 问题不重要 → 不用问
- 心情焦虑时 → 不用问（容易摇错）

### 5. 何时必须用六爻

- 八字看到模糊信号 → 用六爻细化
- 命主面临 A or B 抉择 → 用六爻判方向
- 寻找失物、找人 → 八字无能为力，必用六爻

## 十一、起卦的伦理与禁忌

### ✅ 可以问的

- 自己的事
- 与自己直接相关的事
- 经过对方同意问对方的事

### ❌ 不应问的

- 别人的隐私（道德底线）
- 已经确定的事（无意义）
- 涉及伤害他人的事（如"我要害他怎么做"）
- 重复同一问题（不诚则不灵）

### ⚠️ 禁忌

- 醉酒后起卦
- 极度情绪化时起卦
- 玩笑式起卦
- 同一日同一事多次起卦

## 十二、六爻速查清单

### 起卦 → 断卦标准流程

- [ ] 心诚念问，问题明确
- [ ] 摇卦或起卦
- [ ] 装天干地支（纳甲）
- [ ] 装六亲
- [ ] 装世应
- [ ] 找用神
- [ ] 看用神在月建、日建的旺衰
- [ ] 看动爻对用神的影响
- [ ] 看原神 / 忌神状态
- [ ] 综合判断成败
- [ ] 判应期

### 用神速查

| 求问 | 用神 |
|------|------|
| 自己 | 世爻 |
| 婚事（男看妻、女看夫） | 男看妻财、女看官鬼 |
| 财运、生意 | 妻财 |
| 工作、考试、官非 | 官鬼 |
| 学业、文书、合同 | 父母 |
| 子女、医药、技艺 | 子孙 |
| 朋友、合伙、兄弟 | 兄弟 |
| 失物 | 妻财 |
| 出行、走失 | 用神 + 看动静 |
| 疾病 | 世爻（自己）+ 官鬼（病）+ 子孙（药） |

### 用神有力 / 无力速判

**有力**：
- 临月建（当令）
- 临日建（当日）
- 被动爻生
- 化吉（动而变旺）

**无力**：
- 被月建 / 日建克
- 被动爻克
- 入墓
- 空亡
- 化凶（动而变衰）

## 十三、常见 FAQ

### Q1：六爻和八字哪个准？
A：**不可比较**。它们解决不同的问题。
- 八字看长期趋势
- 六爻看具体事项
- 各有 60-70% 的准确率范围

### Q2：六爻为什么有时不准？
A：常见原因：
- 起卦时不诚（心散）
- 问题模糊
- 自己装卦装错
- 用神判断错
- 应期判断错

### Q3：可以替别人问吗？
A：**最好让对方自己摇**。如果实在不能：
- 必须经对方同意
- 起卦时心中念对方姓名
- 用神：以对方为中心，不是自己

### Q4：摇出"全静卦"代表什么？
A：**事情没有大的变化倾向**。
- 全静 = 一切按现状发展
- 全动 = 一切都在剧烈变化
- 一两个动 = 局部变动

### Q5：六爻可以问"我前世是谁"吗？
A：**不可以**。六爻是问"当下具体事"的工具，不适合形而上的问题。

### Q6：六爻能预测股市吗？
A：**理论上可以，但风险极高**。原因：
- 股市受太多因素影响
- 六爻精度对短线交易不够
- **强烈不建议用六爻指导投资**
- 小额验证可以，大额操作绝对不要

### Q7：学六爻要多久？
A：
- 入门：1-2 个月（会起卦、会装卦、会简单断）
- 中级：1-2 年（多种用神、应期、卦变）
- 高级：5+ 年（疑难案、综合判断）
- **本指南只到入门**，深入需读专业书

### Q8：六爻和梅花易数有什么区别？
A：
- 六爻：**纳甲法**，重五行生克、月日旺衰、应期精确
- 梅花：**取象法**，重卦象、卦意、易理（更接近《周易》本意）
- 六爻规则严谨、梅花直觉性强
- 六爻断具体事更准、梅花断意境更好
- 高手两者结合用

## 十四、本指南的核心总结

> 1. **六爻是"具体事件占卜"的工具**——补充八字看"具体此事"的不足
> 2. **核心元素**：用神、原神、忌神、动爻、世应、月建、日建
> 3. **断卦核心规则**：用神有力 + 原神有力 + 动爻有利 = 事成；反之事败
> 4. **应期口诀**：静则逢冲、动则逢合、合则逢冲、冲则逢合
> 5. **与八字结合**：八字看大势、六爻看具体；八字模糊处用六爻补
> 6. **使用边界**：一事一问、心诚念专、不替别人乱问
> 7. **学习建议**：本指南是入门，深入需读专业书

> **最重要的提醒**：六爻是工具，不是命运的最终裁判。摇卦不是为了"算定结果"，是为了**辅助决策**。算出来的"凶卦"不必执行命运，可以通过行动改变。

> 全文完。
