## 三、按学习阶段的路径 ⭐⭐

### 阶段 1：入门（1-3 个月）

**目标**：能排盘 + 理解基础概念

**必读顺序**：
1. `yijing-foundation.md` — 哲学基础（建立世界观）
2. `wuxing-tables.md` — 五行 / 干支 / 十神基础表
3. `shichen-table.md` + `rizhu-algorithm.md` — 学会排盘
4. `dizhi-canggan.md` — 地支藏干
5. `tiangan-heke.md` + `xing-chong-he-hai.md` — 干支关系
6. `shishen-analysis.md` — 十神基础
7. `bazi-strength-rating.md` — 日主旺衰
8. `choosing-yongshen.md` — 用神确定

**练习**：给自己和家人排盘，判断旺衰和用神

### 阶段 2：进阶（3-12 个月）

**目标**：能完整分析一个八字

**必读顺序**：
1. `tiangan-xingqing.md` — 十天干性情（断命第一步）
2. `special-formats.md` — 特殊格局
3. `dayun-rules.md` + `dayun-liuyear-interaction.md` — 大运流年
4. `tiekou-guize.md` + `yingqi-duanshi.md` — 断事技法
5. `shensha-complete-system.md` + `shensha-liunian.md` — 神煞
6. `liuqin-jinglun.md` — 六亲
7. `jibing-yuce.md` — 健康
8. `mingli-misjudgments.md` — **避坑（重要！）**

**练习**：完整分析 50+ 个命例，做历史校准

### 阶段 3：专业（1-3 年）

**目标**：能做专业咨询

**必读顺序**：
1. 经典深化：`ditian-suiyu.md`、`zipin-zhenquan-sishen.md`、`tiaohou-yongshen.md`、`shenfeng-bingyao.md`、`yuanhai-zipin-fuwen.md`
2. 流派：`manpai-school.md`、`li-hanchen-school.md`、`hong-kong-taiwan-school.md`
3. 精度链：`liuyue-duanshi.md`、`liuri-duanshi.md`、`dayun-jiaojie.md`
4. 咨询：`mingli-zixun-liucheng.md` — **咨询流程**
5. 辅助系统：`ziwei-bazi-jiaocha.md`、`liuyao-fuzhu.md`、`meihua-yishu.md`

**练习**：300+ 命例，开始咨询实践

### 阶段 4：大师（3 年+）

**目标**：融会贯通、形成个人风格

**方向**：
1. 跨学科：`wuyun-liuqi-bazi.md`（中医）、`bazi-mbti-jiaocha.md`（心理）、`xiangshu-bazi.md`（相术）
2. 决策方法论：`juece-zonghe.md` — **统领全局**
3. 哲学升华：`mingli-history.md`、`mingli-kexue.md`
4. 1000+ 命例 + 持续复盘
