> 本文件提供"见到即可直接断"的硬规则——不需要 AI 做复杂推理，只需要**查表匹配**。

> **使用方法**：在第三阶段"关卡 7：铁口断事"中，逐年扫描流年干支，与命局对照本表，找到匹配的硬规则即可断事。

## 十、使用说明

### 如何用本表断事

1. **排出命局四柱 + 大运序列**
2. **确定用神忌神**（经过历史校准后的）
3. **逐年扫描**：从当前年份往前推 10-15 年，逐年查：
   - 该年流年干支与命局形成什么关系？（冲/合/刑/透/值）
   - 对照本表，是否匹配任何硬规则？
   - 匹配了 → 直接输出对应断语
4. **信号叠加**：同一年匹配 2 条以上规则 → 该年必有大事（多条叠加准确率更高）
5. **区分吉凶方向**：同样是"冲日支"，用神被冲=凶，忌神被冲=吉

### 准确率说明

| 准确率范围 | 含义 |
|-----------|------|
| 80-85% | 高置信度，可以直接断 |
| 70-79% | 中高置信度，建议说"极大概率" |
| 65-69% | 中等置信度，建议说"可能性较高" |
| <65% | 仅作参考，不宜作为主要断语 |

### 多规则叠加效应

| 匹配规则数 | 置信度 |
|-----------|--------|
| 1 条 | 按该条本身准确率 |
| 2 条同时满足 | 原准确率 + 10% |
| 3 条同时满足 | 几乎可以"铁口直断"（90%+） |

## 十一、注意事项

1. **硬规则不能脱离格局**：同样的"冲日支"，对不同格局的人意味着不同的事
2. **用神忌神是前提**：所有规则的"吉凶方向"都依赖于用神忌神的正确判断
3. **不能只看一条**：必须综合命局整体结构，单条规则可能被其他因素化解
4. **年份可能偏移 ±1 年**：如果某年的信号只差一点，可能延迟到次年应验
5. **同一冲可以有多种应事**：比如"冲日支"可以是离婚，也可以是搬家——需要结合六亲和宫位细判

## 十二、检查清单

- [ ] 是否已逐年扫描了过去 10-15 年的流年干支？
- [ ] 是否对照了本表的所有大类（婚姻/事业/财运/健康/搬迁/生育/父母/学业）？
- [ ] 是否找到了 3-5 个"信号最强"的年份？
- [ ] 是否区分了吉凶方向（用神被冲=凶，忌神被冲=吉）？
- [ ] 多条规则叠加的年份是否特别标注了？
- [ ] 断语是否足够具体（有年份+有具体事项+有原因链）？
- [ ] 是否与用户的历史校准结果一致？（不一致则需要调整）
