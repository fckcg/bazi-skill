# 现实反馈与预测验证

只排盘不收集人生事件。传统解读中的历史事件收集为可选，用户不提供也可继续。
知道历史事件后调整解释属于回顾性拟合，不能称为预测命中。
不得因事件对不上就要求用户修改出生记录；先核对记录、时区、计算和约定。
如评估预测：提前记录规则版本、原始输入、预测内容、期限、判定标准；结果揭晓后记录命中、漏报、误报。
规则调整案例与最终评估案例分开；与仅使用年龄/现实背景的基准比较；报告样本量及不确定性。
三件事吻合不能推导具体准确率，多流派一致也不能换算成概率。
实际建议先收集具体困扰、行为例子、环境与用户目标，约定一项可执行调整和复盘时间；报告实际反馈，不捏造有效性。
