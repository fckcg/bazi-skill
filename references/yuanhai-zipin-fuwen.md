# 《渊海子平》核心赋文逐句解析

## 一、总论

《渊海子平》是中国子平命理学的奠基之作，由宋代徐升整理（书中包含徐子平的命学体系，以及前代《珞琭子三命消息赋》《李虚中命书》的精华）。它把唐代以**年柱**为主的"古法命理"转向以**日干**为核心的"子平新法"——这是命理史上最重要的转折。

> **本指南聚焦《渊海子平》中最经典的几篇赋文**，逐句解析其义理、举例、现代应用：
> 1. 《继善篇》——子平命理的"心法总纲"
> 2. 《元理赋》——格局与十神精要
> 3. 《络绎赋》——实战论命要诀
> 4. 《五言独步》——简洁口诀总结
> 5. 《喜忌篇》——格局喜忌速查
> 6. 《通玄赋》——疑难破解之钥

### 阅读说明

- 每条赋文先列**原文**（古文）
- 再做**白话直译**
- 再做**深度解读**（命理逻辑）
- 配合**实例**（八字举证）
- 列**现代应用**（如何用到当代分析）

> ⚠️ 古赋文有些观点带有时代局限（性别歧视、宿命论等），本指南采取"批判性继承"原则——保留命理智慧，剔除糟粕。

## 二、《继善篇》逐句解析（核心心法）

《继善篇》是《渊海子平》中最重要的一篇，被称为"子平命理的总纲"。共约 60 句，本指南选取最经典的 30 条详解。

### 第 1 条：人禀天地命属阴阳

**原文**：
> 人禀天地，命属阴阳。生居覆载之内，尽在五行之中。

**白话**：
人类承受天地之气而生，命运归属于阴阳的法则。一生处在天地之间，全部被五行规律所统摄。

**深度解读**：
- 这是子平命理的**哲学起点**——"天人合一"的世界观
- 天地 = 时空背景；阴阳 = 二元对立统一；五行 = 物质能量分类
- 一切命理推算都建立在这个框架上

**现代应用**：
- 反对"命理是迷信"的简单批判——它有完整的世界观基础
- 也反对"命理决定一切"的极端宿命论——人在五行中，但也有能动性

### 第 2 条：欲知贵贱先观月令

**原文**：
> 欲知贵贱，先观月令乃提纲；次断吉凶，专用日干为主本。

**白话**：
要判断一个人富贵贫贱的格局基调，先看月令（出生月份）作为命局总纲；再判断具体吉凶时，以日干为核心。

**深度解读**：
- **"月令为提纲"** —— 月令决定格局（正官格、伤官格等）
- **"日干为主本"** —— 日干代表自己，所有十神都从日干推算
- 这两句话奠定了**子平命理的基本方法论**

**实例**：
- 命主：庚午 戊寅 甲子 丙寅
- 月令为寅 → 寅中藏甲、丙、戊 → 月令本气甲木（比肩）→ 不利成格 → 看是否成"建禄格"
- 日干甲木 → 一切十神以甲木为基准

**现代应用**：
- 排盘后**先看月令** → 决定格局方向
- 再以日干为中心 → 看与其他七字的关系
- 这是 1000 年来不变的金科玉律

---

### 第 3 条：三元要成格局四柱喜见财官

**原文**：
> 三元要成格局，四柱喜见财官。

**白话**：
天元（天干）、地元（地支）、人元（藏干）三者要配合成有用的格局；四柱命局中喜欢见到财星和官星。

**深度解读**：
- **三元** = 天干（天元）、地支（地元）、藏干（人元）
- 命局好坏不只看天干显象，还要看地支藏干的隐藏力量
- 财官并见 = **理想的"富贵"组合**（财生官，官护财）

**现代应用**：
- 看八字不能只看天干 → 必须把地支藏干都列出
- 男命求富贵 → 财官并见为最佳
- 但**身弱不能担财官** → 要先论旺衰再论财官

---

### 第 4 条：用神不可损伤日主最宜健旺

**原文**：
> 用神不可损伤，日主最宜健旺。

**白话**：
用神不能被损伤，日主最适合健旺。

**深度解读**：
- 用神 = 命局所最需要的五行
- 用神被克 / 被合 / 被冲 → 命局功能瘫痪
- 日主健旺 = 自己有能量去使用用神
- 身弱用神不能用 → 等于有钱不会花

**实例**：
- 身弱的人见到偏财大旺 → 不仅得不到，反被财所累（财多身弱反为贫）
- 身旺的人见到适度官星 → 能担官位 → 必有所成

**现代应用**：
- 看命第一步永远是**先看日主旺衰**
- 第二步**确定用神**
- 第三步看**用神状态**（健旺还是被损）
- 三步缺一不可

---

### 第 5 条：年根月令日主时通

**原文**：
> 年根为身命之主，月令乃提纲。日主为我之神，时辰乃归宿之地。

**白话**：
年柱代表本源、根基；月令是格局的提纲；日干是"我"的核心；时柱是命运的归宿。

**深度解读**：
- 每柱有不同的"职能"
- **年柱**：根基、家世、童年、远祖
- **月柱**：青年、父母、事业基础、提纲
- **日柱**：自己、配偶、青年到中年
- **时柱**：晚年、子女、归宿

**现代应用**：
- 论命时按"四柱位置"看人生不同阶段
- 论六亲时"年看祖、月看父母、日看配偶、时看子女"
- 论事业时"月柱看主业、时柱看副业 / 晚年事业"

---

### 第 6 条：明阴阳别五行造化

**原文**：
> 须分阴阳之造化，要明五行之消息。

**白话**：
必须分清阴阳的造化原理，要明白五行的消长规律。

**深度解读**：
- **阴阳造化**：阳生阴成、阴极阳生（动态平衡）
- **五行消息**：消（衰减）+ 息（增长）= 五行能量的此消彼长
- 命理本质是"动态变化的能量场"，不是静止的标签

**现代应用**：
- 不要把命理看成"算固定结果"
- 要看到**动态变化**：大运流年的消长
- 流年中某五行长 → 同类十神事件来；某五行消 → 该类事件去

---

### 第 7 条：四柱有用方为贵

**原文**：
> 四柱中所喜者，乃为吉神，所忌者乃为凶煞。

**白话**：
命局中需要的就是吉神，命局中忌讳的就是凶煞。

**深度解读**：
- **吉神 / 凶煞 不是绝对** —— 同样一个十神，对不同人作用不同
- 用神为财者：财即吉神
- 忌神为财者：财即凶煞
- 这就是为什么"算命不能套用通用模板"

**现代应用**：
- 不要简单说"七杀就是凶"——身旺者七杀是用神
- 不要简单说"正官就是吉"——身弱者官多反为压
- **必须个性化分析**

---

### 第 8 条：会逢禄马自然成福

**原文**：
> 会逢禄马，自然成福之家。

**白话**：
命局中会合禄星（临官位）和驿马，自然成为有福之家。

**深度解读**：
- **禄** = 临官，主财禄、官禄
- **驿马** = 主迁动、远行、贸易
- 禄马同位 = 又有财禄又有动力 = 富贵之命

**实例**：
- 甲木日主，禄在寅，驿马也在寅（地支三合驿马的查法）
- 命中寅 = 禄马同宫 = 大吉

**现代应用**：
- 适合从事**外贸、出差多、远行类**的工作
- 求职、求事业方向时考虑"动中求财"

---

### 第 9 条：财官印绶全备

**原文**：
> 财官印绶全备，将相公侯之命。

**白话**：
命中财、官、印都齐备，是大富大贵（将相公侯）的命。

**深度解读**：
- **财** → 财富、妻缘、资源
- **官** → 权力、地位、贵人
- **印** → 智慧、文化、贵人、护身
- **三者俱全 + 流通有序** → 完美命局

**现代应用**：
- 现代解读："财官印俱全"= 钱、权、文化资本三者兼备
- 不一定是"将相公侯"，可以是企业家、学者、政府高官等
- **关键是三者要"流通有情"**（财生官、官生印、印生身）

### 第 10 条：金白水清两全

**原文**：
> 金白水清，秋月最宜。

**白话**：
金清水白的格局，秋天的月令最为适宜。

**深度解读**：
- **金白水清** = 金水相生格
- 庚辛日主生于秋月（申酉戌），有水透出 = 金清水秀
- 主**清贵、文人、学者、艺术家**
- 现代典型：从事文化、教育、艺术的高级人才

**实例**：
- 庚申 乙酉 庚申 壬午
- 庚日生酉月 = 秋金当令；时干壬水透出 = 金水相生
- 此命金白水清，宜文学、写作

**现代应用**：
- 适合学术、文学、出版、影视编剧、艺术
- 需要"用心经营自己的清雅气质"

### 第 11 条：木火通明

**原文**：
> 木火通明，春木最宜火。

**白话**：
木火通明的格局，春天的木最适合见到火。

**深度解读**：
- **木火通明** = 春木日主生于寅卯月，有火透出
- 主**才华横溢、口才好、有传播力**
- 现代典型：演员、网红、教师、传媒人

**实例**：
- 甲寅 丙寅 甲午 丁卯
- 甲日生寅月木旺，丙丁火透出 → 木火通明
- 主才华显露、易出名

**现代应用**：
- 适合传媒、教育、演艺、自媒体
- 在九运（火当令）下尤其有利

---

### 第 12 条：水暖金温

**原文**：
> 冬金喜火相济，谓之水暖金温。

**白话**：
冬天的金需要火来调候，称为水暖金温。

**深度解读**：
- 冬月生庚辛日主 → 金寒水冷 → 必须有火调候
- 调候用神是命理的"必需品"，不是"奢侈品"
- 没有调候火 = 命局阴寒 = 多灾、健康差

**实例**：
- 辛亥 庚子 辛丑 戊子
- 辛日生子月，水多金寒 → 必须见丙丁火
- 若无火 → 一生劳碌、多病
- 若有火（如时干透丙）→ 富贵之命

**现代应用**：
- 冬月生金日主者 → 居家忌阴冷，要多接触阳光、暖光
- 大运流年走火地（巳午未戌等）→ 大利
- 调候是 60% 命例的核心（详见 `tiaohou-yongshen.md`）

### 第 13 条：从化得真

**原文**：
> 从化得真，不论格局而自有富贵。

**白话**：
从格、化气格如果"真"成立，不必论普通格局，自然富贵。

**深度解读**：
- **从格**：日主极弱时反而顺从某一旺势
- **化气格**：日主与某一干合化为另一五行
- "得真"= 完全成立的从格 / 化气格 → 反而是大富贵命
- "假从"或"假化"= 半真半假 → 反成劳碌命

**实例**：
- 戊辰 戊午 戊戌 戊午
- 全是戊土 + 月支午（火生土）→ 土极旺，无木来克
- 此为"从旺格"，不论身旺身弱
- 主**大富贵**

**现代应用**：
- 看到极偏的八字（一气专旺、二气两旺）不要按常规分析
- 要考虑从格、化气格（详见 `special-formats.md`）
- 这类命局往往是大成之人

### 第 14 条：伤官见官为祸百端

**原文**：
> 伤官见官，为祸百端。

**白话**：
命中伤官又见正官，会带来各种祸患。

**深度解读**：
- **伤官**：克正官的十神 → 与官星天然冲突
- 伤官见官 = "我"既想叛逆又想顺服 → 内在分裂
- 主**与上司冲突、官非、口舌、婚变（女命）**

**实例**：
- 己卯 乙亥 丁未 庚子
- 丁日干，伤官为戊己土，正官为壬癸水
- 命中年柱己土（伤官）+ 时支子水（正官）→ 伤官见官
- 此人易与上司冲突、官非缠身

**例外**：
- 若伤官有制（食神制伤）或印星化伤 → 可解
- "伤官见官，为祸百端" 不是绝对，需看整体格局

**现代应用**：
- 提醒：不要轻易跳槽（伤官冲动）
- 不要与上级正面冲突
- 女命伤官重者：婚姻需特别经营
- 现代社会不必太忌讳——可以做"自由职业者"避开"官"的局面

### 第 15 条：劫财羊刃切忌时逢

**原文**：
> 劫财羊刃，切忌时逢。岁运逢之，灾殃立至。

**白话**：
劫财、羊刃最怕时柱出现。大运流年再遇到，灾祸立刻到来。

**深度解读**：
- **羊刃**：阳干日主的劫财坐帝旺（如甲日卯支为羊刃）
- 羊刃在时柱 → 主**晚年破财、子女不和**
- 大运流年再加冲 → 大凶之兆

**实例**：
- 庚午 甲申 庚申 辛卯（庚日羊刃为酉，但时支卯反冲，仅作示例）
- 严格的羊刃在时：庚申 庚辰 庚申 庚酉

**现代应用**：
- 时柱有羊刃者：晚年慎入合伙投资
- 大运流年走羊刃位：注意意外伤害
- 不必恐慌 → 提前预警，谨慎度过

### 第 16 条：印绶生身大忌财乡

**原文**：
> 印绶生身，大忌财乡。

**白话**：
靠印星生身的命局，最怕走财大运、流年（财克印）。

**深度解读**：
- 身弱用印 → 印星是命局的支柱
- 财星克印 → 用神被克 = 大凶
- "印绶生身" 的命：走财乡 = 母病、丢工作、健康问题、贵人远去

**实例**：
- 辛卯 辛卯 甲午 戊辰
- 日主甲木弱，靠印（水）生身（实际此命无水印，仅作教学）
- 类似身弱用印的命：走财大运（戊土等克水印）= 大凶

**现代应用**：
- 身弱用印的人：尽量不进入"财上"行业（投资、贸易）
- 走财大运时多读书、求贵人（强化印星）

### 第 17 条：财多身弱反为贫

**原文**：
> 财多身弱，反为贫薄之命。

**白话**：
财星多但日主弱，反而是贫困的命。

**深度解读**：
- 这是初学者最容易误判的：以为"财多就是富"
- **真相**：财多必须身能担 → 身弱见财 = "见财起意，财不归我"
- 主**奔波劳碌、有钱难存、被财所累**

**实例**：
- 辛卯 辛卯 甲午 戊辰
- 甲木日主在卯月得令（不弱），但戊辰土多+辛酉金克 → 整体偏弱
- 戊辰为偏财，财多身弱 → 此人易追求财利，但难以守财

**现代应用**：
- 财多身弱者 → 不要做投机、做生意（容易败）
- 适合做**稳定工作、领固定工资**
- 走比劫大运可助身担财 → 此运是发财机会

### 第 18 条：官星太重日主受伤

**原文**：
> 官星太重，日主受伤。

**白话**：
正官星太多太重，日主反被压伤。

**深度解读**：
- 一个正官 = 升职加薪的好事
- 三四个正官 = 压力山大、健康受损
- "官多变为杀，杀重身轻必有灾"

**实例**：
- 辛酉 辛酉 甲申 庚午
- 甲木日主，庚辛官杀过多 → 必有压制、官非、健康危机
- 必须用印（水）化杀生身

**现代应用**：
- 官杀重的命：不宜在"高压"环境（如军队、警察、外科医生）
- 适合"自由度高"的职业（设计、自由撰稿、咨询）
- 必须重视身心调适、定期体检

### 第 19 条：女命伤官伤夫子

**原文**：
> 女命伤官，必克夫子。

**白话**：
女命有伤官，必克丈夫和子女。

**深度解读**：
- 这是古赋的**性别歧视部分**，需批判看待
- 古义：女命以官为夫，伤官克官 → 克夫
- **现代视角**：
  - 伤官重的女命 = 个性强、有才华、不愿被束缚
  - 在传统社会被视为"克夫"，因为不愿做附属
  - 在现代社会反而是**事业型女性的特质**
  - "克夫"= 不适合做妻子身份 ≠ 婚姻必败
  - 关键是**对方能否欣赏她的独立性**

**重要警示**：
- 此条**不可生硬套用**到现代女命
- 古代视角下的"克夫"，现代往往是"独立有成"
- 重点是匹配"能欣赏独立女性"的伴侣，而非压制女性

### 第 20 条：男命比肩劫财夺妻

**原文**：
> 男命比劫重重，必克妻夺财。

**白话**：
男命比劫多，必克妻、损财。

**深度解读**：
- 比劫 = 兄弟朋友
- 男命财为妻
- 比劫克财 → 兄弟朋友夺妻 / 朋友借钱不还 / 自己分财给人
- 主**婚姻多波折、财来财去**

**实例**：
- 甲寅 甲寅 甲寅 乙亥
- 五个甲乙木 + 甲日主 → 比劫极重
- 财（戊己土）几乎无根 → 财来无情、妻缘多变

**现代应用**：
- 男命比劫重 → 不宜与朋友合伙
- 不要做"借贷"业务
- 婚姻需谨慎选择 → 易遇有竞争的桃花局面
- 走食伤大运可化比劫 → 此运是稳定期

## 三、《元理赋》核心摘录

《元理赋》是《渊海子平》中关于格局、十神的精要篇。

### 第 1 条：年时见伤官早岁不利

**原文**：
> 年时上伤官，早年防双亲不利。

**白话**：
年柱、时柱上有伤官，早年防双亲不利。

**深度解读**：
- 年柱代表父母，时柱代表晚辈
- 伤官克官 → 克父亲（男）、夫君（女）
- 早岁伤官 → 童年与父母关系不顺

**现代应用**：
- 现代视角："早年与父母不和"= 童年原生家庭压力
- 不必视为"克父母"
- 心理学上 → 这类人需要修复童年关系才能内在自洽

### 第 2 条：日时刑冲晚年凶

**原文**：
> 日时相刑相冲，晚年子女多刑伤。

**白话**：
日柱与时柱相刑相冲，晚年与子女关系多有刑伤。

**深度解读**：
- 日柱 = 自己 + 配偶
- 时柱 = 子女 + 晚年
- 日时刑冲 → 自己与子女关系、晚年生活多波折

**现代应用**：
- 提前注意亲子关系经营
- 投资养老、避免过度依赖子女
- 子女远走他乡是常态（刑冲的现代体现）

### 第 3 条：印多财弱辛劳

**原文**：
> 印多财弱，必致辛勤劳苦。

**白话**：
印星多、财星弱，必然劳苦奔波。

**深度解读**：
- 印多 = 想得多、依赖性强、文人气
- 财弱 = 没有变现能力
- "知识不能变现的人" → 一辈子勉强温饱

**现代应用**：
- 学历高但收入不高的人 → 多此命
- 改善方法：走财大运、努力将"知识"转化为"产品"
- 现代社会"个人 IP""知识付费"是这类人的出路

### 第 4 条：财官印俱足必富贵

**原文**：
> 财官印俱足，男必富贵显达，女必荣夫益子。

**白话**：
财、官、印俱全，男的富贵显达，女的旺夫益子。

**深度解读**：
- 财生官、官生印、印生身 → 流通完美
- 男命：钱、权、文化俱全 → 大成
- 女命：旺夫益子（古义） → 现代视角是"全面发展型女性"

### 第 5 条：印破财损母不全

**原文**：
> 印破财损，母先去而父在。

**白话**：
印星被破、财星损坏 → 母亲先离开，父亲仍在。

**深度解读**：
- 印为母 → 印破 → 母不寿
- 财为父 → 财损 → 父不寿
- 古赋常断"父母先后顺序"

**现代应用**：
- **不可机械直断**——现代医学已大幅改变寿命
- 仅作"概率参考" → 提示提前关注父母健康
- 重点是"加强母亲健康管理"，不是"接受不可改变的命运"

## 四、《络绎赋》核心摘录

《络绎赋》是论命的实战要诀。

### 第 1 条：日干为主月令为重

**原文**：
> 日干为主，看月令以分轻重。

**白话**：
以日干为主体，看月令以分清旺衰轻重。

### 第 2 条：先看格局后论喜忌

**原文**：
> 先看格局之纯杂，后论喜忌之归一。

**白话**：
先看格局是纯还是杂（成格还是破格），再论喜神忌神归宿到哪。

### 第 3 条：身旺财官两得

**原文**：
> 身旺财官两旺，定主荣华富贵。

**白话**：
日主旺 + 财官也旺 = 必定荣华富贵。

### 第 4 条：身弱再行劫地

**原文**：
> 身弱再行比劫之地，反主大发。

**白话**：
身弱的人走比劫大运，反而大发。

**深度解读**：
- 身弱见比劫 = 兄弟朋友帮身
- 大运是"运"，不在原命局，所以不存在"夺财"问题（在大运中比劫主"得力"）
- 此运 = 求贵人、合伙、扩展人脉的好运

### 第 5 条：枭神夺食断子绝孙

**原文**：
> 枭神夺食，断子绝孙。

**白话**：
偏印（枭神）克食神，断子绝孙。

**深度解读**：
- 古义：食神 = 子女星（男命）
- 枭神克食 → 克子
- **现代视角**：
  - 不一定真"绝后"——医学进步、试管婴儿等手段
  - 心理上：偏印重者**养育子女有压力**（吹毛求疵、控制欲强）
  - 实际表现：晚婚晚育、与子女疏离

### 第 6 条：贪财坏印名利不就

**原文**：
> 贪财坏印，名利不就。

**白话**：
贪财而坏了印星 → 名利都成不了。

**深度解读**：
- 印 = 名声、文化、贵人
- 财克印 → 为了钱，名声、贵人都失去
- "为五斗米折腰"的命局体现

**现代应用**：
- 学者、知识工作者过度商业化 → 失去学术声誉
- 提醒"知识工作者不要轻易用名声换钱"

### 第 7 条：合官留杀威权显赫

**原文**：
> 合官留杀，威权显赫。

**白话**：
合住正官、留下七杀，威权显赫。

**深度解读**：
- 官 + 杀同现 = 官杀混杂 → 不利
- 把官合掉、留杀 → 反而清纯
- 七杀有制 = 大将之命

**实例**：
- 甲木日主 + 庚（杀）+ 辛（官）+ 丙（食制杀）+ 戌（合卯——若有卯）
- 留下的七杀+食神制 = 武贵命

**现代应用**：
- 适合从军、从警、做高管、做律师等"威权"行业
- 现代版"合官留杀"= 选择压力更大但成就更高的赛道

## 五、《五言独步》摘录（简洁口诀）

《五言独步》是用五言形式写的命理口诀，简洁有力。

### 1. **金水多伤人，水木多富贵**
- 金水多 + 调候不足 → 多病多伤
- 水木 + 适度火 → 富贵之兆

### 2. **木火多文章，金水重诗词**
- 木火格局 → 主文章、传播
- 金水格局 → 主诗词、艺术

### 3. **官杀混杂者，必至于穷困**
- 官杀混杂未制 → 多劳少得

### 4. **财多身又弱，富屋贫人耳**
- 财多身弱 → 看似有钱，实则贫困

### 5. **比劫多须财官制**
- 比劫多必有财官来制 → 才能成器

### 6. **食神制杀格，威权天下闻**
- 食神制七杀 → 大成之命

### 7. **印绶逢财坏，名利皆无处**
- 印被财破 → 名利皆失

### 8. **桃花日时见，男女易风流**
- 日时柱见桃花 → 异性缘旺、易婚外情

### 9. **驿马生日时，必主奔波劳**
- 驿马在日时 → 一辈子奔波

### 10. **食伤泄秀者，才艺动人间**
- 食神或伤官泄日主 → 才华显露

## 六、《喜忌篇》核心摘录

《喜忌篇》专门讲各种格局的喜忌。

**忌**：

**忌**：
- 比劫劫财
- 财星无根

### 食神格喜忌

- 食神生财（食神生财格最佳）

**忌**：
- 枭神夺食

- 伤官生财（伤官生财格）

**忌**：

### 印绶格喜忌

**忌**：

### 比劫格 / 建禄格 / 羊刃格喜忌

## 七、《通玄赋》核心摘录

《通玄赋》是论疑难命局的核心赋文。

### 第 1 条：阳刃驾杀威权万里

**原文**：
> 阳刃驾杀，威权万里。

**白话**：
阳刃配合七杀 → 威权万里。

**深度解读**：
- 阳刃（劫财坐帝旺）+ 七杀
- 阳刃为"匕首"，七杀为"敌人"
- 用刀杀敌 → 立功
- 主**军警、外科医生、武职高官**

### 第 2 条：化气格成主大富贵

**原文**：
> 化气得真，主大富大贵。

**白话**：
化气格如果真成立 → 大富大贵。

### 第 3 条：从财从杀俱可富

**原文**：
> 从财从杀，俱可富贵。

**白话**：
从财格、从杀格都可富贵（前提是真从）。

### 第 4 条：天地交泰主升迁

**原文**：
> 天合地合，谓之天地交泰。

**白话**：
天干合 + 地支合 = 天地交泰，主升迁、合作成、姻缘成。

### 第 5 条：禄运并临必发福

**原文**：
> 禄运并临，必有大发。

**白话**：
禄（临官）和大运同时到位，必有大发达。

## 八、综合实战应用

### 1. 看一个八字时的"赋文检查清单"

依据本指南，看到一个八字，可以问以下问题：

- [ ] 月令何字？格局何来？（继善篇 #2）
- [ ] 日干旺衰如何？用神是什么？（继善篇 #4）
- [ ] 财官印是否齐备、流通？（继善篇 #9 / 元理赋 #4）
- [ ] 是否走入"伤官见官"陷阱？（继善篇 #14）
- [ ] 是否"财多身弱"？（继善篇 #17）
- [ ] 是否"身旺财官两旺"？（络绎赋 #3）
- [ ] 调候用神是否到位？（继善篇 #12）
- [ ] 是否有从格 / 化气格嫌疑？（继善篇 #13）
- [ ] 比劫多吗？是否需财官来制？（五言独步 #5）
- [ ] 是否有"贪财坏印"等反差？（络绎赋 #6）

### 2. 古赋文的现代翻译表

| 古义 | 现代翻译 | 现代应用 |
|------|---------|---------|
| 富贵 | 财富 + 地位 | 多元成功（不止官位） |
| 贫贱 | 物质匮乏 + 社会地位低 | 经济压力 + 自我认同低 |
| 克夫克妻 | 婚姻不顺 | 婚姻经营难度大 |
| 绝后 | 无子嗣 | 生育困难 / 不愿生育 / 现代医学可解 |
| 官非 | 法律纠纷 | 合同纠纷、诉讼、行政处罚 |
| 病灾 | 疾病、灾祸 | 健康预警、意外预防 |
| 福禄寿全 | 福气 + 财禄 + 长寿 | 综合幸福指数高 |
| 横财 | 意外之财 | 副业、投资、奖金、遗产 |
| 桃花 | 异性缘 | 感情活跃 + 风险 |

### 3. 古赋文的"祛魅"原则

**保留**：
- 阴阳五行、十神、长生等技术体系
- "用神""调候""病药"等核心方法
- 流通有情、平衡和谐的命理审美

**改造**：
- "克夫克妻"→ 婚姻匹配难度
- "贵贱"→ 社会成就的多元理解
- "绝后"→ 现代生育观下重新理解

**摒弃**：
- 极端宿命论（"必"克、"绝"灾）
- 性别歧视（女命不如男命的偏见）
- "破解必收高费"的商业话术

## 十二、本指南的核心总结

> 1. **古赋文是命理智慧的浓缩**——但不能照搬到现代
> 2. **核心心法**：日干为主、月令为提纲、用神不可伤、日主宜健旺
> 3. **关键公式**：身旺 + 财官并见 + 流通有情 = 大富贵
> 4. **常见陷阱**：伤官见官、财多身弱、印破财坏
> 5. **批判性继承**：保留智慧、改造时代局限、摒弃迷信
> 6. **古今融汇**：用古赋的逻辑分析现代命例，给出现代化的人生建议

> **真正的命理高手，是"读懂赋文 + 看懂现代 + 兼顾人性"的三才合一**。
