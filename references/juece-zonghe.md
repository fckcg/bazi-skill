# 重大人生决策综合命理法（元方法论）

## 一、总论

> **人生由一系列重大决策构成：选专业、选职业、选伴侣、选城市、要不要创业、要不要移民……本指南是整合全部命理模块的"决策辅助元方法论"。**

### 本指南的定位

- 不是新的命理知识，而是**整合全部模块的"决策框架"**
- 教你在面临重大抉择时，如何系统地用命理辅助决策
- 是整个 skill 的"收官方法论"

### 命理决策的核心理念

> **命理不替你做决定，命理帮你"看清牌面"，决定权永远在你手里。**

```
重大决策 = 命理参考（30%） + 现实分析（40%） + 个人意愿（30%）
```

### 本指南覆盖

1. 决策的命理三要素
2. 重大决策的标准评估流程
3. 不同决策类型的命理框架
4. 多模块综合运用法
5. 决策时机的判断
6. 决策的伦理边界

## 二、决策的命理三要素 ⭐

### 要素 1：方向（适不适合）

**核心问题**：这个选择符合我的命格吗？
- 用神方向匹配吗？
- 十神格局适合吗？
- 是顺势还是逆势？

**工具**：用神、格局、职业匹配（`zhiye-pipei-xiandai.md`）

### 要素 2：时机（什么时候做）

**核心问题**：现在是做这件事的好时机吗？
- 大运是否支持？
- 流年是否有利？
- 流月 / 流日的具体时机？

**工具**：大运、流年（`dayun-liuyear-interaction.md`）、流月（`liuyue-duanshi.md`）、流日（`liuri-duanshi.md`）

### 要素 3：风险（有什么坑）

**核心问题**：这个决策有什么潜在风险？
- 忌神方向的风险
- 破财 / 官非 / 健康信号
- 关键预警

**工具**：误判避坑（`mingli-misjudgments.md`）、各专题的风险预警

## 三、重大决策的标准评估流程（7 步法）⭐⭐

### 第 1 步：明确决策内容

- 你要做什么决定？（具体、清晰）
- 有哪些选项？（A / B / C）
- 决策的时间窗口？

### 第 2 步：排盘 + 确定命格基础

- 完整八字
- 用神 / 忌神
- 主导格局
- 当前大运

### 第 3 步：方向评估（适不适合）

- 各选项是否符合用神方向？
- 各选项是否符合命格特质？
- 给每个选项打"匹配度分"

### 第 4 步：时机评估（什么时候）

- 当前大运是否支持？
- 流年是否有利？
- 如需精确 → 流月 / 流日

### 第 5 步：风险评估（有什么坑）

- 各选项的潜在风险
- 关键预警信号
- 化解方案

### 第 6 步：六爻辅助（如有具体疑问）

- 对最纠结的选项摇卦
- 详见 `liuyao-fuzhu.md`
- 八字看大势 + 六爻看具体

### 第 7 步：综合决策建议

```
【决策综合分析】

决策内容：[具体决策]

选项对比：
| 选项 | 方向匹配 | 时机 | 风险 | 综合评分 |
|------|---------|------|------|---------|
| A | ⭐⭐⭐⭐ | 有利 | 低 | 推荐 |
| B | ⭐⭐ | 一般 | 中 | 谨慎 |
| C | ⭐ | 不利 | 高 | 不推荐 |

命理建议：[倾向哪个选项 + 原因]
现实考量：[需要结合的现实因素]
最终决定权：[强调在用户手里]
```

## 五、多模块综合运用法 ⭐

### 综合运用的层次

```
第 1 层：基础排盘（所有决策的起点）
    ↓
第 2 层：方向判断（用神 / 格局 / 职业匹配）
    ↓
第 3 层：时机判断（大运 → 流年 → 流月 → 流日）
    ↓
第 4 层：风险预警（误判避坑 + 专题风险）
    ↓
第 5 层：辅助验证（紫微 / 六爻 / 历史校准）
    ↓
第 6 层：综合决策（命理 + 现实 + 意愿）
```

### 双系统 / 三系统验证

**重大决策建议多系统验证**：
- 八字（主）：`SKILL.md` 主流程
- 紫微（辅）：`ziwei-bazi-jiaocha.md`
- 六爻（辅）：`liuyao-fuzhu.md`
- 三者一致 → 信心最高
- 三者矛盾 → 谨慎 + 倾向保守

### 历史校准提升准确度

- 重大决策前先做历史校准
- 验证用神判断是否正确
- 详见 `mingli-misjudgments.md`、`SKILL.md` 第 2.5 阶段

## 六、决策时机的判断 ⭐

### 1. 时机判断的精度层次

| 决策类型 | 时机精度 | 工具 |
|---------|---------|------|
| 人生方向（移民/创业） | 大运（10 年） | 大运分析 |
| 年度计划（转行/结婚） | 流年（1 年） | 流年分析 |
| 月度行动（签约/启动） | 流月（1 月） | `liuyue-duanshi.md` |
| 具体日期（开业/手术） | 流日（1 日） | `liuri-duanshi.md`、`zeri.md` |

### 2. "红绿灯"综合判断

```
🟢 绿灯（全力做）：
- 方向匹配（用神方向）
- 时机有利（大运 + 流年用神）
- 风险可控
- 现实条件成熟

🟡 黄灯（谨慎做 / 小规模试）：
- 方向匹配但时机一般
- 或时机好但方向有疑虑
- → 小规模尝试 / 等待更好时机

🔴 红灯（不做 / 推迟）：
- 方向不匹配（逆用神）
- 或时机不利（忌神大运 + 凶流年）
- 或风险过高
- → 推迟 / 放弃 / 换方向
```

### 3. 时机与现实的平衡

- 命理时机最佳 ≠ 现实条件成熟
- 现实条件成熟 ≠ 命理时机最佳
- **理想**：两者都成熟时行动
- **现实**：往往需要权衡（现实优先于命理时机）

## 七、典型综合决策案例

### 案例：35 岁的人生十字路口

**命主**：女，1990 年生
**八字**：庚午 戊寅 甲子 丙寅
- 日干甲木，用神金 + 水
- 当前面临三选一：
  - A：留在大厂升职
  - B：跳槽到创业公司
  - C：自己创业

**第 1-2 步**：排盘 + 命格
- 食神丙火透出（创新表达）+ 偏财（戊土）
- 身旺、有挑战需求

**第 3 步：方向评估**
| 选项 | 方向匹配 |
|------|---------|
| A 大厂升职 | ⭐⭐⭐（稳定但压抑食伤） |
| B 创业公司 | ⭐⭐⭐⭐（释放食伤 + 有平台） |
| C 自己创业 | ⭐⭐⭐⭐⭐（最释放，但风险高） |

**第 4 步：时机评估**
- 当前大运是否用神运？（假设用神运起点）→ 有利
- 流年配合 → 适合变动

**第 5 步：风险评估**
- C 创业风险最高（需资金 + 团队）
- 身旺能担，但需现实条件

**第 6 步：六爻辅助**
- 对 B、C 分别摇卦验证

**第 7 步：综合建议**
```
命理倾向：C（自己创业）方向最匹配，但风险最高
折中方案：先选 B（创业公司）—— 释放食伤 + 积累经验 + 降低风险
        2-3 年后若大运 + 流年配合 → 再转 C（自己创业）

现实考量：评估资金储备、家庭责任
最终决定：在你手里。命理建议"B 过渡 → C 进阶"的路径
```

## 八、决策的伦理边界 ⭐

### 1. 命理不替你做决定

- 命理是"参考工具"
- 决定权永远在当事人
- 不能用"命理说的"逃避责任

### 2. 现实优先于命理

- 命理时机 ≠ 现实条件
- 重大决策必须结合现实（经济、家庭、能力）
- 不能脱离现实空谈命理

### 3. 不制造决策焦虑

- 不说"你必须 X 否则大凶"
- 给选项 + 利弊，让当事人选
- 决策本身就有不确定性，这是正常的

### 4. 专业问题找专业人士

- 法律决策 → 律师
- 医疗决策 → 医生
- 投资决策 → 投资顾问
- 命理只作"额外维度的参考"

## 九、决策综合法 FAQ

### Q1：重大决策一定要算命吗？
A：**不一定，但有帮助**。命理提供"额外的参考维度"，让决策更全面。但最终靠"命理 + 现实 + 意愿"综合。

### Q2：命理和现实冲突时听谁的？
A：**现实优先**。命理时机再好，现实条件不成熟也不能硬上。理想是两者都成熟时行动。

### Q3：三系统（八字/紫微/六爻）矛盾怎么办？
A：**倾向保守**。三系统矛盾说明信号不明确，此时宜谨慎、不冒进、或等待更明朗的时机。

### Q4：怎么用命理做"要不要"的二选一决策？
A：
- 对每个选项做"方向 + 时机 + 风险"评估
- 六爻摇卦辅助
- 综合打分
- 但最终结合现实 + 意愿

### Q5：命理决策准确率多高？
A：**方向判断 70%、时机判断 60%、综合约 65%**。是"提升决策质量的工具"，不是"保证正确的神器"。
